                                                          Test pour validation

| Scénario                                                          | Étapes                                                                                                                                                                                                                                                       | Résultat attendu                                                                                                                                        |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PT-01 — Accès au parcours « Mot de passe oublié »**             | 1. Ouvrir l’écran de connexion TicketPulse.<br>2. Cliquer sur « Mot de passe oublié ? ».                                                                                                                                                                     | L’écran demandant l’adresse courrielle s’affiche.                                                                                                       |
| **PT-02 — Demande avec un courriel valide**                       | 1. Saisir l’adresse d’un compte existant.<br>2. Cliquer sur « Envoyer ».<br>3. Vérifier la réception du code et sa durée de validité.                                                                                                                        | La demande est acceptée, un code est envoyé au courriel indiqué et ce code demeure valide pendant 5 minutes.                                            |
| **PT-03 — Courriel au format invalide**                           | 1. Saisir une adresse incomplète, par exemple `alex.tremblay@`.<br>2. Cliquer sur « Envoyer ».                                                                                                                                                               | La demande n’est pas transmise et le système demande une adresse courrielle valide.                                                                     |
| **PT-04 — Courriel inexistant**                                   | 1. Saisir une adresse courrielle qui n’est associée à aucun compte.<br>2. Cliquer sur « Envoyer ».                                                                                                                                                           | Le système affiche le message d’erreur prévu et aucun code de réinitialisation utilisable n’est créé.                                                   |
| **PT-05 — Code valide avant expiration**                          | 1. Saisir le code reçu.<br>2. Valider le code dans les 5 minutes suivant son émission.                                                                                                                                                                       | Le code est accepté et l’écran de création du nouveau mot de passe s’affiche.                                                                           |
| **PT-06 — Code expiré**                                           | 1. Attendre plus de 5 minutes après l’émission du code.<br>2. Saisir le code.<br>3. Cliquer sur « Valider ».                                                                                                                                                 | Le code est refusé et un message indique qu’il a expiré.                                                                                                |
| **PT-07 — Nouveau mot de passe valide**                           | 1. Saisir un mot de passe d’au moins 8 caractères.<br>2. Vérifier qu’il commence par une lettre et contient une majuscule, un chiffre et un caractère spécial.<br>3. Saisir la même valeur dans le champ de confirmation.<br>4. Cliquer sur « Enregistrer ». | Le mot de passe est accepté et la demande de mise à jour est exécutée.                                                                                  |
| **PT-08 — Nouveau mot de passe non conforme**                     | 1. Tester successivement un mot de passe trop court, ne commençant pas par une lettre, sans majuscule, sans chiffre ou sans caractère spécial.<br>2. Cliquer sur « Enregistrer » pour chaque variante.                                                       | Le système refuse chaque mot de passe non conforme et indique clairement la règle qui n’est pas respectée.                                              |
| **PT-09 — Confirmation différente**                               | 1. Saisir un nouveau mot de passe valide.<br>2. Saisir une valeur différente dans « Confirmer le mot de passe ».<br>3. Cliquer sur « Enregistrer ».                                                                                                          | La mise à jour est refusée et un message indique que les deux mots de passe ne correspondent pas.                                                       |
| **PT-10 — Mise à jour et connexion avec le nouveau mot de passe** | 1. Terminer la réinitialisation avec des données valides.<br>2. Revenir à l’interface de connexion.<br>3. Tenter une connexion avec l’ancien mot de passe.<br>4. Tenter ensuite une connexion avec le nouveau mot de passe.                                  | L’ancien mot de passe est refusé, le nouveau mot de passe permet la connexion et l’interface de connexion est affichée après la réinitialisation.       |
| **PT-11 — Protection du mot de passe**                            | 1. Effectuer une réinitialisation réussie.<br>2. Vérifier la valeur enregistrée dans la base de données ou au moyen des outils d’administration autorisés.                                                                                                   | Le mot de passe n’est jamais stocké en clair; seule une représentation hachée et sécurisée est conservée.                                               |
| **PT-12 — Performance du parcours**                               | 1. Mesurer la réponse lors de l’envoi du courriel.<br>2. Mesurer la validation du code.<br>3. Mesurer la mise à jour du mot de passe.                                                                                                                        | Pour chacune des trois opérations, la réponse applicative est affichée en moins de 2 secondes dans les conditions normales de test.                     |
| **PT-13 — Journalisation de la demande**                          | 1. Déclencher une demande de réinitialisation.<br>2. Consulter les journaux applicatifs autorisés.<br>3. Vérifier les informations enregistrées.                                                                                                             | La demande est journalisée avec la date, le résultat et les informations techniques nécessaires, sans exposer le mot de passe ni le code de validation. |
