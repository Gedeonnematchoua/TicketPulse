PLAN DE TESTS DE VALIDATION DU PARCOURS DE CONNEXION

TEST 1
- l'utilisateur entre correctement son adresse courriel ou son nom d'utilisateur et son mot de passe
- Résultat attendu: Connexion réussi, une nouvelle page s'ouvre.

TEST 2
- L'utilisateur entre correctement son adresse courriel ou son nom d'utilisateur mais saisi mal son mot de passe
- Résultat attendu: Erreur. Mot de passe incorrect

TEST 3
- L'utilisateur saisit mal son adresse courriel ou son nom d'utilisateur,
- Résultat attendu: Impossible de se connecter

TEST 4
- Adresse courriel/nom d'utilisateur et mot de passe incorrects
- Résultat attendu: Connexion impossible. Erreur de mot de passe et/ou nom d'utilisateur

TEST 5
- Temps de réponse
- résultat attendu: réponse en moins de 2 secondes
