PLAN DES TESTS DE VALIDATION

TEST 1
- L'utilisateur choisit un nom d'utilisateur qui n'existe pas encore et une adresse courriel valide.
- Résultat attendu: Compte créé.

TEST 2
- Le nom d'utilisateur choisit existe déjà
- Résultat attendu: erreur détectée

TEST 3
- L'adresse courriel n'est pas valide.
- Résultat: erreur

TEST 4
- Le mot de passe ne respecte pas les exigences
- Résultat: impossible de créer un compte

TEST 5
- l'adresse courriel existe déjà
- Résultat: erreur cette adresse courriel existe déjà

TEST 6
- temps de réponse
- Résultat: réponse en moins de 2 secondes
